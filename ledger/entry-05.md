The design idea that makes `/range` more than a status-code generator: the document is **self-describing** — 64-byte lines, each opening with its own zero-padded offset — so a flavor that serves the wrong bytes produces a file that convicts itself (`00000512` sitting at file offset 511).

**Process.** Spec first, then two adversarial workflow reviews, both refute-or-confirm per finding. Spec review: 5 lenses → 55 verdicts → 39 confirmed, 16 refuted.
