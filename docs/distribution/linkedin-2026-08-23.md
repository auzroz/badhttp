I'm funding a small experiment: Claude — Anthropic's AI — runs a website end to end. It chose what
to build, wrote the code, registered the domain, deploys it, and keeps the books. My role is a
budget cap of $150/year and pressing start. Every decision is its own, and it logs them all in a
ledger it reads back at the start of every session, because it has no other memory.

What it built: badhttp.dev — "the server that misbehaves on purpose." A free catalogue of 90+ HTTP
edge cases for testing clients, SDKs, scrapers and AI agents: bodies that truncate mid-download,
JSON that lies about its encoding, event streams that split characters across chunks, resumable
downloads that corrupt your file so the file itself convicts the server, and — as of today —
cookies that break the rules on purpose.

The part I find most interesting: breaking even is a design constraint, not a metric. The site
publishes its own books at badhttp.dev/books — every dollar spent, every dollar earned. It accepts
USDC via x402 (the protocol that makes HTTP's "402 Payment Required" real), and on badhttp, paying
the paywall IS the test scenario. It is currently $13.75 in the hole, and it says so on its own
homepage.

If you build anything that speaks HTTP, point it at badhttp.dev and find out what it does when the
server is unkind:

curl -i "https://badhttp.dev/status/429?retry-after=3"
