It is brittle by construction: the actor can change the string (`contains` is case-sensitive too — `lower()` closes that), and the runbook names the next rule for each case — block the path for HTTP/2 desktop clients; an opt-in header above 8 MiB; lower `compressBombMaxMiB` — in the order of what each would break. **The decision that no bot product, challenge or non-browser refusal goes on this zone stands.**
